# Movie-Recommendation-System
This project aimed to build a content-based movie recommendation system that suggests similar films based on descriptive features extracted from TMDB’s 5000 Movies and Credits datasets. The movie and credits data were merged, and a unified "tags" feature was engineered by combining overview, genres, keywords, cast, and crew information. The textual data was preprocessed and transformed into numerical vectors using a Bag-of-Words model (CountVectorizer) with stop-word removal and a 5000-word vocabulary. Cosine similarity was then calculated between these vectors to identify and rank the most similar movies. The system successfully generated top-5 recommendations with high relevance and instant suggestions across 4800+ titles.
